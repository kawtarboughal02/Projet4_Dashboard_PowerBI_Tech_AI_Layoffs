PRÉREQUIS
--------------------------------------------------------------------------------

- Power BI Desktop (version gratuite, Windows)
  Téléchargement : https://powerbi.microsoft.com/desktop/

- Jeu de données source (non inclus dans ce dépôt)
  Source : Global AI & Tech Layoffs Dataset (2020–2026) sur Kaggle
  URL : https://www.kaggle.com/datasets/prajitdatta/global-ai-and-tech-layoffs-dataset-20202026
  Le fichier doit être enregistré sous le nom : tech_market_raw.csv

--------------------------------------------------------------------------------
OUVERTURE DU PROJET
--------------------------------------------------------------------------------

1. Télécharger le jeu de données depuis Kaggle (voir data/README_donnees.md)
   et l'enregistrer sous le nom tech_market_raw.csv.

2. Ouvrir le fichier :
   powerbi/tech_ai_layoffs_dashboard.pbix

   avec Power BI Desktop.

3. Si Power BI signale une source introuvable :
   - Accueil → Transformer les données
   - Sélectionner Faits_Licenciements
   - Ouvrir l'étape Source dans le panneau Étapes appliquées
   - Indiquer le chemin du fichier tech_market_raw.csv

4. Accueil → Actualiser pour recharger les données.
